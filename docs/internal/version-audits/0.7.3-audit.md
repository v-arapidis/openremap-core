## Remaining (non-blocking)

1. **Cargo version skew** — `Cargo.toml`/`Cargo.lock` at 0.7.2 while Python
   is 0.7.3. The wheel version comes from `pyproject.toml`, so nothing user
   facing breaks, but 0.7.2 shipped consistent — bump before tag (one-line
   change + `cargo update -p openremap --manifest-path openremap/_rs/Cargo.toml`).
2. **`attach_maps(xrefs=…)` unwired and untested** — the changelog's
   "surfaced in … the recipe `maps[]` annotation" is a library-surface claim
   only: no shipped command passes `xrefs`, and the parameter has zero test
   coverage. Either wire it into `cook`/TUI (needs an xref pass over the
   stock) or soften the changelog wording; add a small test either way.
3. **Coverage numbers** — align "14" (changelog bullet) with the measured 15
   of 36; refresh AGENTS.md's "35 extractors" when convenient.
4. **EDC17 headline numbers are v1-era** — "~121 refs / 14 tables / 0.855 /
   ≈4 s" predate the a0/DPP work landing and don't reproduce exactly
   (structure verifies; numbers don't). Re-measure on the intended file or
   soften to "~10²–10³ references depending on the file".
5. **pyo3 0.25 advisory** — unchanged from 0.7.1/0.7.2, not exploitable in
   this crate per AGENTS.md, remediation still planned for the 0.7.x cycle.

## Recommendation

**Ship.** The full suite is green (6,154 passed; 8/8 cargo tests), and the
release's highest-risk claims were re-verified against the real corpus and
the Ghidra oracle rather than taken from the changelog: the C166 decoder has
zero decode disagreements against Ghidra (re-run this session), the DPP path
recovers ME7's true flash base on 4 of 5 ME7-family bins with the 5th
correctly reporting no signal, the cascade fork-isolation survives a
reproduced capstone crash, MS43 identifies HIGH with full identity/checksum/arch
agreement, and the presence-only contract holds everywhere (every negative
case reports clean zero evidence, never a wrong bonus). The five remaining
items are a one-line version bump, doc/number alignment, one unwired optional
parameter, stale measurements, and the known pyo3 advisory — none
release-blocking, though the Cargo bump (item 1) is worth doing before the
tag.
