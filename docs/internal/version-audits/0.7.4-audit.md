## Remaining (non-blocking; 0.7.4 is live)

1. **Changelog mischaracterization** — "No runtime-code changes … docs +
   versioning only" is false: the SpanIndex + entropy-limit performance work
   shipped in this commit undocumented in any changelog. Behavior is
   unchanged and tested, so nothing user-facing is wrong — but the release
   record should acknowledge it (fold a line into a future changelog, or a
   note in `changelog/0.7.4.md`).
2. **Wiki analyze→decoders link** — one-line fix in the docs repo
   (`../concepts/` → `../../concepts/` in `commands/analyze/index.md`).
3. **pyo3 0.25.1 shipped** — the known advisory pair
   (RUSTSEC-2026-0176/0177, not exploitable in this crate) was still compiled
   in at 0.7.4; remediation (0.29.2) lands in the pending 0.7.5.
