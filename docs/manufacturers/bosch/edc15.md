# EDC15

The workhorse diesel platform of the early 2000s. Two sub-formats:
**Format A** (TSW header) and **Format B** (C3-fill).

| | |
|---|---|
| Era | 1997–2004 |
| File sizes | 512 KB |
| Variants | EDC15C2 (Alfa/Fiat/Lancia common-rail), EDC15C3 (Volvo D5), EDC15C5 (VAG 1.9 TDI) |
| Vehicles | VAG, Fiat, Volvo, BMW diesel |

## Detection

TSW header or C3-fill signature + size gate. **Checksums:** no family
profile (generic sweep only).
