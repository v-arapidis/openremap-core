# 0.7.4 — 2026-08-28

The documentation release — the wiki and README brought fully in line
with the 0.7.3 arch/decoder work: a new **decoders** concept page, the
**MS43** manufacturer page promoted from checksum-only to a full
extractor entry, extractor-count corrections (35 → 36, Siemens 6 → 7)
across every index, and README links updated for the live wiki.  No
runtime-code changes; Python + Rust versions synced to 0.7.4.

### Added

- **Decoders concept page** — what the CPU
  decoders are (C166 in Rust, TriCore/SuperH via capstone) and how they
  power the code-reference signal, the CPU-detection cascade, and the
  decoder tag in `analyze`.  Wired into the concepts hub, the wiki
  index, "How it works", and the `analyze` command page.
- **README links block** — openremap.com, docs.openremap.com, and the
  open-source docs repo (`v-arapidis/openremap-docs`) now lead the
  README, each with a one-line description.

### Changed

- **MS43 manufacturer page** — rewritten from "checksum-only, no
  extractor in the registry" to the full extractor entry (Siemens/MS43,
  program number `430069`, Siemens part `5WK90027`, match key
  `MS43::<program number>`).
- **Public docs moved to the open-source wiki repo** — the user-facing
  wiki content now lives in [`v-arapidis/openremap-docs`](https://github.com/v-arapidis/openremap-docs)
  (self-contained, served at docs.openremap.com); this repository keeps
  only `docs/internal/` (audits, roadmaps, integration).  README and all
  in-repo references updated to the live wiki / docs repo; internal
  docstring pointers corrected to `docs/internal/audits/…`; zero broken
  links (verified).
- **Extractor counts everywhere** — 35 → 36 extractors (Siemens 6 → 7)
  in the README, the wiki index, the manufacturers / families /
  architecture / quickstart pages, and the integration doc; MS43 added
  to the families table.
- **"How it works"** — new "Decoders & the code-reference signal"
  section; extractor count corrected.
- **README Documentation section** — leads with the live wiki URL and
  notes that new pages need a website manifest update first.
- **Wiki link sweep** — 359 internal links verified; the one broken
  cross-reference (the decoders link on the analyze page) was corrected.

### Fixed

- (no runtime fixes — this release is docs + versioning only)
